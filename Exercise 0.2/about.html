Project Objectives

This demonstration web application is structured to satisfy core front-end software development standards: semantic HTML5 layout structuring, clean CSS3 styling, vanilla JavaScript DOM manipulation, and responsive user feedback mechanisms.

Implemented Architecture

  • Semantic Markup: Clean separation of document structure using standard elements (`header`, `nav`, `main`, `section`, `footer`).
  • CSS Design System: Custom typography, consistent button states, dynamic cards, and a theme drawn directly from the site's power logo.
  • Vanilla JavaScript (ES6+): Zero external dependencies, secure input validation, dynamic calculation models, and collapsible UI accordion behaviour.
